What "working" looks like:
Load this page after building the bundle (npm run build:webflow). Hovering the first paragraph should make each word nearest the cursor grow heavier and wider (wght 300→800, wdth 75→125), easing back over ~220 ms when the cursor leaves. In the second paragraph, only the confusable characters (I l 1) should widen as the cursor passes over them, while the rest of the text stays put. With no cursor movement, nothing animates (the rAF loop is idle). window.MagnetType exposes init, destroy, and restart for manual control. Respects prefers-reduced-motion: with it enabled, the plain text renders and no listeners attach.
